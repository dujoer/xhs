# 小红书图文带货工作台

一个**纯前端、零后端**的个人带货效率面板，数据保存在浏览器 localStorage，可直接用 GitHub Pages 托管。

## 在线访问
🌐 https://dujoer.github.io/xhs/

## 包含的模块
- 🛒 选品库（1688 代发友好品类 + 佣金参考）
- 📅 笔记排期 + 数据（标题/选题/状态/赞藏评/阅读）
- 🏆 标题 / 选题库（标签循环：待试 → 已用 → 爆了）
- 📈 收益看板（近 7 天柱状图）
- 🎯 对标 / 爆款库（含第三方 API 接入）
- 🚀 今天发什么（智能推荐待发布笔记）
- 📊 数据透视（SVG 图表：收益趋势 / 笔记 TOP5）
- 🗓️ 内容日历（月视图）
- ✍️ 笔记草稿生成器（选品类自动产出封面/标题/正文/标签，一键复制）
- 📚 图文带货实战手册（9 个可抄的方法论标签页）

## 本地使用
直接双击 `index.html` 用浏览器打开即可。数据默认存在本机浏览器，记得用顶栏「导出备份」留存。

## 同步到 GitHub
本仓库通过 `sync.js`（GitHub REST API）同步，绕开被代理拦截的 git 协议。
换行说明见项目说明，token 存于本地 `.sync-config.json`，不会上传。
