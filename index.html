图文带货完整链路

① 选品→ ② 选题→ ③ 做图→ ④ 写文案→ ⑤ 发布→ ⑥ 看数据→ ⑦ 复制爆款

每一步做什么

  • 选品：蒲公英 / 选品中心，挑高佣金、体验分高、有爆文的产品
  • 选题：搜核心词看高赞在聊啥，挖痛点与长尾词
  • 做图：3:4 竖版，一张图一个主体，对比图最吸睛
  • 写文案：4 段式（经历→痛点→解法→行动）
  • 发布：黄金时段 + 精准标签（≤5 个）
  • 看数据：盯 CTR 与互动率，达标再放大
  • 复制：把跑赢的选题 / 封面 / 结构沉淀成模板

新手起号节奏

  • 先发 3 篇测试笔记，达标再生产，别盲目日更
  • 前 5 篇标签要一致，垂直度 ≥70%
  • 每周 3–5 篇，48h 内回评，互动留存 >60%
  • 每天刷同行并点赞，3 天平台会推更多同行

爆款封面公式 可抄

品类封面公式案例
美妆护肤对比图 + 文字标签左脸瑕疵 vs 右脸遮瑕，配「油痘肌救星」
穿搭全身搭配 + 显瘦标记梨形身材试穿，显瘦部位箭头标注
家居场景图 + 箭头指示凌乱卧室 vs 整洁，箭头指收纳神器
知识 / 干货白底黑字 + 重点标红「月瘦10斤饮食表」，关键数字标红

通用 4 要素

  • 主体突出：一个封面只聚焦一个核心元素，靠近镜头
  • 文案点睛：白底黑字 / 黄底黑字，戳「干货 / 避坑 / 新手」
  • 画质精美：自然光、中心构图，美食暖调 / 护肤冷调
  • 对比强烈：Before / After 制造冲击（护肤 / 健身 / 家居）

规格与红线

  • 比例 3:4 竖版；文字 ≤ 封面 1/3 面积
  • 重点信息放上半部，避免被头像遮挡
  • 别过度美颜 / 网图，用户觉得不真实
  • 首图加 2–3 个关键词标签，增强搜索匹配

爆款标题公式 可抄

类型公式实例
数字型具体数字 + 效果承诺「3个技巧让脱发减少80%」
痛点型人群 + 问题 + 解法「油痘肌必看！3步拯救反复长痘」
结果型结果 + 时间周期「喝它一周，痘痘全消了」
悬念型好奇 + 价值暗示「这个10元小物让化妆台整洁10倍」
对比型前后对比 + 惊讶「原来以前都错了！这样洗脸毛孔小一半」
颠覆型反常识 + 性价比「别买贵了！30块防晒霜暴打大牌」
技巧：加数字提质感；用「必看 / 救命 / 神器」情绪词；避免「震惊 / 99%人不知道」标题党；把核心关键词写进标题利于搜索。

正文黄金结构 可抄

4 段式写法

  • ① 经历引入：用「我」建立真实信任（我是混油皮…）
  • ② 痛点放大：引发共鸣（试过很多都卡粉…）
  • ③ 产品解法：核心卖点（直到遇见XX，持妆8h）
  • ④ 效果 + 行动：促成转化（链接放左下角啦）

比例 & 细节

  • 高转化内容 ≈ 30%干货 + 50%场景 + 20%互动
  • 开头黄金前 20 字直击痛点
  • 多用「我」少用「产品」；写强说服细节（「油头实测3天没塌」）
  • 结尾抛开放式问题引导评论（「你们最想看哪款测评？」）
  • 图文笔记建议 ≥600 字，更易获推荐

选品策略 可抄

佣金率参考

  • 美妆个护 10–20% ｜ 母婴 15–25%
  • 家居 15–30% ｜ 数码 5–12%
  • 大健康 / 部分家居可达 35%+

选品金字塔

  • 底层 60%：50–200元 实用小物
  • 中层 30%：200–800元 体验型
  • 顶层 10%：800元+ 决策型

去哪选

  • 蒲公英 / 选品中心：筛「高佣金 + 近30天热度高 + 已有爆文」
  • 看佣金比率高、体验分高、销量趋势好
  • 从评论区「求推荐」挖真实痛点

赛道定位

  • 美妆：平价替代 / 成分党 ｜ 穿搭：显瘦 / 百元内
  • 家居：租房神器 / 收纳 ｜ 母婴：高性价比
  • 数码：学生党平价 / 黑科技
把你看中的品填进「选品库」，标好佣金%和状态，月底看「收益看板」算 ROI。

对标 / 竞品拆解（照着抄） 可抄

去哪找对标

  • 搜核心词 → 筛「近一周高赞」爆款笔记
  • 每天刷同行并点赞，3 天平台推更多同行
  • 看同领域头部最近在推什么

6 维度拆解清单

  • □ 选题角度（它踩中什么痛点 / 热点）
  • □ 标题句式（数字 / 痛点 / 对比哪种）
  • □ 封面风格（对比图 / 白底字 / 场景）
  • □ 正文结构（4段式？比例？）
  • □ 标签组合（大词 + 细分 + 长尾）
  • □ 发布时间 & 互动钩子

复刻方法

  • 抄结构、不抄文案：复刻黄金结构，替换成你的产品与真实体验
  • 例：「通勤党口红推荐」→「学生党百元内口红测评」
  • 把跑赢的笔记记进「对标 / 爆款库」，点一下标记「已借鉴」

标签组合策略

黄金组合公式

  • 1 个行业大词（200万+笔记）：#彩妆
  • 2 个细分词（50–100万）：#平价彩妆 #学生党彩妆
  • 1 个长尾词（10–30万）：#2025彩妆新品
  • 1 个活动标：#小红书美妆节
总数 ≤5 个，过多稀释权重；正文里自然揉入关键词（SEO），别硬塞。

数据健康度自测

指标公式健康区间
点击率 CTR阅读÷曝光5–15%，<5% 改封面标题，>15% 爆款潜质
互动率(赞+藏+评+分享)÷阅读图文≥2.5% 及格，好的是 5%，爆款 8%+
完读率读完÷阅读图文 >30% 健康
涨粉率新增关注÷阅读0.5–2%+ 健康

自查口诀

  • 高曝光低点击 → 封面 / 标题问题
  • 高点击低互动 → 内容不如预期（标题党风险）
  • 高互动低涨粉 → 人设关联弱

每周复盘

  • 选互动率最高的 3 篇，总结成功模式
  • 找完读率最低的 2 篇，分析流失原因
  • 追踪带来最多新粉的内容类型，加大投入
填了笔记的「阅读 / 赞藏评」后，下方「数据透视」会自动算你的平均互动率。

发布 & 避坑红线

发布时段

  • 早 7–9 ｜ 午 12–14 ｜ 晚 19–22
  • 评论区用小号 / 朋友在发后 1h 带节奏

权重维护

  • 前 5 篇标签一致，垂直度 ≥70%
  • 每周 3–5 篇；48h 内回评；互动留存 >60%
  • 信用分满分 100，>90 有流量加持

红线（别踩）

  • 单日删 >3 篇扣信用分 10
  • 违规一次扣 5–20 分
  • 合作笔记必须标「合作」
  • 禁用绝对化用语（治愈 / 根除 / 100%）

引流技巧

  • 热门笔记下回「求链接」并附你的链接
  • 自己评论区置顶抽奖 / QA 提互动率
  • 评论区高赞反馈可截图当新素材
